# Aplikasi Pemesanan Tiket

Aplikasi mobile sederhana untuk melakukan pemesanan tiket dengan perhitungan total bayar secara dinamis dan fitur reset jumlah tiket.

---

## 🚀 Fitur Utama

- **Harga Tiket**: Menampilkan harga tiket per lembar (Rp25.000).
- **Pengatur Jumlah Tiket**:
  - Tombol **+** untuk menambah jumlah tiket.
  - Tombol **-** untuk mengurangi jumlah tiket (minimal 1 tiket).
- **Kalkulasi Otomatis**: Total bayar diperbarui secara otomatis sesuai dengan jumlah tiket yang dipesan.
- **Tombol Reset**: Mengembalikan jumlah pemesanan tiket ke kondisi awal (1 tiket).
